IFCC Events

Over het project

IFCC Events is een platform bestaande uit een Laravel/Filament backend en een Expo mobiele applicatie. Het platform wordt gebruikt voor het beheren en presenteren van congressen, artikelen, presentaties, sprekers, kanalen, menu's en andere evenementgerelateerde content.

  • Een Laravel- en Filament backend voor contentbeheer
  • Een Expo mobiele applicatie voor bezoekers
  • Publicatie naar Google Play Store en Apple App Store

Belangrijkste onderdelen

Database & Models

Artikelen, presentaties en sprekers vormen de basis van het platform.

Expo App

Dynamische content wordt vanuit de Laravel API in de mobiele applicatie geladen.

Plan: Filament

1. Database Structure and Basic Models

Articles, Presentations en Speakers worden opgezet met Models, Resources en Controllers.

2. API Development

Een REST API wordt ontwikkeld voor de integratie met de Expo mobiele applicatie.

3. Channel Management

Channels kunnen actief worden gemaakt en er kan een main channel worden ingesteld.

4. Authentication & Rollen

QR-codes bevatten een Personal Access Token via Laravel Sanctum. Voor rollen wordt Spatie Permission gebruikt met Super Admin, Editor en Officer.

5. Dynamische menu's

Menu-structuren kunnen per channel worden ingesteld en via drag-and-drop worden beheerd.

6. Map making

SVG-paden, punten en blokken worden herkend zodat een interactieve 2D-kaart kan worden opgebouwd vanuit JPEG, JPG of PNG.

7. Page-Maker

Pagina's kunnen worden opgebouwd uit verschillende dynamische contentblokken.

  • Heading
  • Paragraph
  • Image
  • Event Info
  • Location
  • Accordion
  • Sponsors

Plan: Expo

Project setup

npx create-expo-app@latest
npx expo start

Lokale Laravel server

php artisan serve --host=0.0.0.0

Tijdens development wordt het lokale IP-adres van de computer gebruikt in plaats van localhost.

Navigation & Screens

Navigation wordt ingesteld in _layout.tsx. Screens worden gemaakt voor Speakers, Articles en Presentations.

Dynamic content blocks

Heading.tsx, Image.tsx, Paragraph.tsx

Een centrale render component bepaalt welk component voor ieder contentblok wordt gebruikt.

Caching

Een stale-while-revalidate hook toont direct gecachte data en ververst deze vervolgens op de achtergrond. Hierdoor blijft eerder geladen data ook offline beschikbaar.

QR-code & Rollen

QR-codes worden gebruikt om toegang te geven tot gesloten meeting content. Rollen en rechten bepalen welke informatie beschikbaar is.

Menus & More Menu

De More Menu structuur is dynamisch. De onderste tabs blijven hardcoded.

Presentations

Presentatieknoppen worden bepaald op basis van channel en de bijbehorende datumrange.

Interactieve kaart

De app krijgt een interactieve kaart met klikbare punten. Bij het selecteren van een punt wordt aanvullende informatie in een modal weergegeven.

Google Play Store

APK bouwen

eas build --platform android --profile production

De eerste builds mislukten door verouderde packages. Na het oplossen hiervan kon de APK succesvol worden gebouwd en getest.

Testen

De APK is getest op een Android-tablet voordat de overstap naar het AAB-formaat werd gemaakt.

Play Store informatie

Privacy policy, data safety, doelgroep, content rating, guidelines, beschrijvingen, iconen, screenshots en API keys werden voorbereid.

Eerste review

De eerste inzending werd afgewezen vanwege een mismatch met het launcher icon. Het icon werd aangepast en de app opnieuw gebouwd.

Lokale AAB build

npx expo prebuild
cd android
./gradlew bundleRelease

Na de aanpassingen werd de app succesvol goedgekeurd en live gezet.

Apple App Store

Technische highlights

Laravel Sanctum

Persoonlijke access tokens worden via QR-codes gebruikt om vanuit de Expo-app toegang te krijgen tot gesloten meeting content.

Rollen & Permissions

Spatie Permission wordt gebruikt om Super Admin-, Editor- en Officer-rechten te beheren.

Dynamische Page-Maker

Content wordt opgebouwd met herbruikbare blokken waardoor verschillende pagina's dynamisch vanuit het CMS kunnen worden samengesteld.

Channel Management

Content, menu's en presentaties kunnen per channel worden beheerd, inclusief actieve channels en datumranges.

Stale-While-Revalidate

De mobiele applicatie gebruikt gecachte data direct en voert daarna een achtergrondupdate uit om de interface actueel te houden.

Code quality & Testing

Laravel Pint en Pest worden gebruikt voor code formatting, testing en het schoonhouden van de codebase.
